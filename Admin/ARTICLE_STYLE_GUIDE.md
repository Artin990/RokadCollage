# راهنمای استایل و رندرینگ مقالات وبلاگ (Article Style Guide)

این مستند راهنمای مشترک میان **تیم داشبورد ادمین** و **تیم کلاینت (فرانت‌اند کاربر نهایی)** برای نمایش یکدست، امن و هماهنگ مقالات وبلاگ کالج رکاد است.

---

## ۱. مسیر فایل استایل و کلاس والد
- **مسیر فایل CSS در پروژه:** `Admin/src/Pages/Blog/styles/articleContent.css`
- **کلاس کانتینر والد:** `.article-content`
- **جهت متن:** `direction: rtl` (به‌همراه پشتیبانی خودکار از بلوک‌های کد LTR)

> **نکته بسیار مهم برای تیم کلاینت:**  
> محتوای فیلد `content` در پاسخ APIهای سرور (`GET /api/blog/:id` و `GET /api/blogs/:id`) از قبل با استانداردهای امنیتی دقیق و سخت‌گیرانه پاکسازی (Sanitize) شده است و تمام تگ‌های خطرناک نظیر `<script>`, `onerror`, `<style>`, `style=""`, و `javascript:` از آن حذف شده‌اند.  
> کافی است خروجی HTML سرور را مستقیماً داخل کانتینر با کلاس `.article-content` قرار داده و از فایل CSS فوق استفاده کنید تا ظاهر نهایی مقاله **دقیقاً و ۱۰۰٪ مشابه پیش‌نمایش داشبورد ادمین** رندر شود.

---

## ۲. فهرست متغیرهای طراحی (`--article-*`)
فایل CSS به صورت خودکفا (Self-Contained) متغیرهای زیر را تعریف کرده است. تیم کلاینت در صورت نیاز می‌تواند این متغیرها را در استایل‌های خود override کند:

| نام متغیر | مقدار پیش‌فرض | توضیحات و کاربرد |
| :--- | :--- | :--- |
| `--article-primary` | `#F8A41D` | رنگ اصلی برند کالج (عناوین هایلایت، بولت لیست‌ها، بوردر نقل‌قول، لینک‌ها) |
| `--article-primary-hover` | `#e08f12` | رنگ هاور لینک‌ها و دکمه‌های متنی داخل مقاله |
| `--article-primary-active` | `#c67c0c` | رنگ حالت کلیک یا فعال لینک‌ها |
| `--article-bg-brand-soft` | `#fef7ec` | پس‌زمینه ملایم برند برای کادرهای نقل‌قول (`blockquote`) |
| `--article-text` | `#1E293B` | رنگ متن اصلی پاراگراف‌ها و محتوا (خوانایی بالا) |
| `--article-text-secondary` | `#475569` | رنگ ثانویه برای نقل‌قول‌ها و توضیحات متنی |
| `--article-text-muted` | `#64748B` | رنگ عناوین کوچک، کپشن تصاویر و زیرنویس‌ها |
| `--article-border` | `#E2E8F0` | خطوط جداکننده (`hr`)، بوردر جداول و کدها |
| `--article-bg-subtle` | `#F8FAFC` | پس‌زمینه هدر جداول و سطرهای یک‌درمیان |
| `--article-code-bg` | `#F1F5F9` | پس‌زمینه کدهای تک‌خطی داخل متن |
| `--article-radius` | `0.75rem` | گردی گوشه تصاویر، جداول، کدهای دستوری و نقل‌قول‌ها |
| `--article-font-family` | `inherit` | فونت مقاله (پیش‌فرض ارث‌بری از فونت سایت: `Vazirmatn`) |
| `--article-line-height` | `1.95` | ارتفاع خطوط بهینه برای مطالعه روان متون طولانی فارسی |

## ۳. نمونه مارک‌آپ استاندارد در صفحه مقاله (Client Markup)

```html
<!-- وارد کردن استایل مقاله در صفحه یا کامپوننت -->
<!-- import './articleContent.css'; -->

<main class="blog-detail-container">
  <!-- سربرگ مقاله (تولید شده توسط کامپوننت ری‌اکت کلاینت) -->
  <header class="blog-header">
    <img src="/uploads/covers/blog-cover.webp" alt="عنوان مقاله" class="blog-cover-image" />
    <span class="blog-category-badge">فرانتاند</span>
    <h1 class="blog-title">راهنمای جامع یادگیری React در سال ۱۴۰۳</h1>
    <p class="blog-excerpt">خلاصه کوتاه و متای مقاله...</p>
  </header>

  <!-- کانتینر رندر محتوای HTML دریافت شده از سرور -->
  <article 
    class="article-content" 
    dir="rtl"
    dangerouslySetInnerHTML={{ __html: blog.content }}
  />
</main>
```

## ۴. المان‌های استاندارد پشتیبانی‌شده در محتوا
1. **عناوین (`h2` تا `h6`):** فاصله‌بندی استاندارد، فونت بولد و خط ته‌رنگ برای `h2`.
2. **پاراگراف‌ها و شکست کلمات:** با فاصله `1.35rem` و `overflow-wrap: anywhere` برای جلوگیری از به‌هم‌ریختگی در صفحات موبایل.
3. **لینک‌ها (`a`):** رنگ برند طلایی/کهربایی با زیرخط و افکت نرم هاور.
4. **لیست‌ها (`ul` و `ol`):** فاصله‌گذاری ایمن در راست‌به‌چپ (`padding-inline-start`) با بولت‌های رنگ برند.
5. **نقل‌قول (`blockquote`):** کادر با نوار کناری ۴ پیکسلی طلایی و پس‌زمینه نرم.
6. **جداول (`table`):** اسکرول افقی خودکار روی موبایل (`overflow-x: auto`)، هدر مشخص و سطرهای راه‌راه.
7. **تصاویر و اشکال (`figure`, `img`, `figcaption`):** ریسپانسیو کامل، گوشه‌های گرد و زیرنویس وسط‌چین.
8. **کدها (`code`, `pre`):** چپ‌چین خودکار (`dir="ltr"` و `text-align: left`) با فونت مونواسپیس، پس‌زمینه تیره برای بلوک‌های چندخطی و اسکرول افقی.
9. **ریسپانسیو (< 600px):** متناسب‌سازی خودکار اندازه قلم عناوین و فواصل برای انواع نمایشگرهای موبایل.
