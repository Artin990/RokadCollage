## 四、AI 绘图提示词生成

根据用户需求，自动生成 Midjourney / Stable Diffusion / DALL-E 提示词。

### 生成流程

1. **确认设计类型**：Logo / 品牌海报 / UI界面 / 包装 / 插画
2. **提取关键词**：风格 + 色彩 + 构图 + 情绪
3. **生成提示词**：结构化输出（英文提示词 + 中文解释）
4. **参数建议**：--ar / --v / --stylize 等参数
