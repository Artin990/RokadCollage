# 行为设计心理学 v1.0

> 从 behavioral-design-psychologist 融合而来，提供八角行为分析、认知偏差、情感化设计、社会认同完整理论体系。

## 一、八角行为分析（Octalysis）

**来源**：Yu-Kai Chou《游戏化实战：人类行为学×游戏机制，打造产品吸引力》

### 8个核心驱动力

| 驱动力 | 类型 | 说明 | 产品应用示例 |
|--------|------|------|--------------|
| **意义与使命** | 白帽/内在 | 感觉自己在做有意义的事 | "你的体质调理将帮助1000人" |
| **进步与成就** | 白帽/内在 | 感觉自己正在成长 | "已完成10个客户跟进，获得'跟进达人'徽章" |
| **创造与反馈** | 白帽/内在 | 感觉自己在创造东西 | "生成我的体质报告" |
| **社交** | 右脑/内在 | 感觉自己与他人有联系 | "分享你的跟进经验给同行" |
| **未知与好奇** | 右脑/内在 | 感觉好奇，想探索 | "明天的体质小贴士是什么？" |
| **稀缺与渴望** | 黑帽/外在 | 感觉想要但得不到 | "仅前100名经销商享受5折优惠" |
| **损失与厌倦** | 黑帽/外在 | 感觉害怕失去 | "会员即将到期，续费立省50元" |
| **拥有** | 左脑/外在 | 感觉自己拥有东西 | "我的体质档案已积累30天数据" |

### 设计原则

1. **避免黑帽依赖**：稀缺/损失/拥有是强驱动力，但长期使用会让用户反感
2. **优先白帽**：意义/进步/创造/社交是可持续的驱动力
3. **混合使用**：根据产品阶段选择合适驱动力（新产品用"未知与好奇"，成熟产品用"进步与成就"）

## 二、认知偏差

### FOMO效应（害怕错过）
- **原理**：人们害怕错过机会，会非理性决策
- **应用**："仅剩3个名额，立即注册！"

### 习惯路径依赖
- **原理**：人们倾向于重复已养成的习惯
- **应用**："连续签到7天，养成每日养生习惯"

### 钩子模型（Hook Model）
- **触发** → **行动** → **多变的奖励** → **投入**
- **应用**：体质测试完成（触发）→ 查看报告（行动）→ 发现"体质偏阴虚"（多变的奖励）→ 输入每日作息数据（投入）

### 多巴胺反馈机制
- **原理**：不确定性奖励比确定性奖励更能刺激多巴胺分泌
- **应用**："连续签到7天，第7天奖励神秘体质调理方案"

## 三、情感化设计

### 三层设计

1. **本能层**：外观好看（如：简洁、专业的UI设计）
2. **行为层**：使用顺畅（如：话术推荐要快、准）
3. **反思层**：情感共鸣（如：温暖、有共情的内容）

### 应用示例

- **温暖色彩**（米色、浅绿）+ **柔和语言**（"您的体质需要温柔对待"）→ 激发用户的关爱和愉悦情感
- **专业图标**（空调、话术库）+ **简洁布局** → 激发用户的信任感

## 四、社会认同与从众心理

**原理**：人们倾向于模仿他人的行为，以减少风险

**应用**：
- "已有500个经销商在使用润锋AI"
- "10万+人正在使用养元家调理体质"

## 六、八角行为分析设计方案模板

```markdown
## 八角行为分析设计方案

### 产品：xxx

### 核心驱动力
1. **进步与成就**（白帽/内在）- 主要驱动力
2. **社交**（右脑/内在）- 辅助驱动力
3. **稀缺与渴望**（黑帽/外在）- 短期刺激

### 驱动机制设计

#### 1. 进步与成就
- **功能**：完成任务获得积分+徽章
- **反馈**：积分排行榜 + 徽章展示

#### 2. 社交
- **功能**：分享经验到同行群，获得额外积分
- **反馈**："已帮助X个同行提升业绩"标签

#### 3. 稀缺与渴望
- **功能**：仅前X名享受优惠
- **反馈**：注册页面显示"仅剩X个名额"

### 实施优先级
- P0：进步与成就（直接影响留存）
- P1：社交（间接影响增长）
- P2：稀缺与渴望（短期刺激，慎用）
```

## 九、注意事项

1. **避免过度游戏化**：不是所有产品都适合游戏化（医疗/金融类产品需谨慎）
2. **避免黑帽滥用**：稀缺/损失/拥有是强驱动力，但长期使用会让用户反感
3. **数据驱动优化**：设计方案必须可量化（如：留存率提升xx%），并通过A/B测试验证
4. **用户体验优先**：行为设计是"术"，用户体验是"道"，不能本末倒置

---

_行为设计不是"操纵"用户，而是"理解"用户——用心理学原理设计出用户真正需要的产品。_
